# Document Worker

Универсальный скилл для работы с документами (Word, Excel, PDF).

## Доступные действия

- `parse_specification` — PDF со спецификацией → Excel (основная + сводная вкладки)
- `create_word` — создание Word-документов
- `create_excel` — создание Excel-отчётов

## Примеры использования

- "Обработай спецификацию из файл.pdf"
- "Создай коммерческое предложение"
