# 🔔 Каналы уведомлений о движении средств (СберБизнес)

Интеграция СберБизнес API проверяет банк каждые 60 секунд через инкрементальный эндпоинт `/v2/statement/increment` и отправляет карточки прихода/списания с суммами и актуальным остатком **быстрее платных СМС банка** (0 ₽ расходов).

Система не привязана жестко к одному мессенджеру — уведомления можно направить в любой канал, удобный пользователю или его бухгалтерии.

---

## 📋 Поддерживаемые каналы доставки

### 1. Telegram (Личка, группа или канал компании)
* **Как настроить:**
  - Создать бота через [@BotFather](https://t.me/BotFather) и получить токен.
  - Добавить бота в группу/канал и получить `chat_id` (например, `-1001234567890`).
* **Конфигурация в `config.json`:**
  ```json
  {
    "channel": "telegram",
    "telegram": {
      "enabled": true,
      "token": "123456789:ABCdefGHIjklMNOpqrSTUvwxYZ",
      "chatId": "-1001234567890"
    }
  }
  ```

---

### 2. MAX Messenger (Личный чат или рабочая группа)
* **Как настроить:**
  - Получить токен бота на портале [business.max.ru](https://business.max.ru).
  - Указать ID пользователя (строкой) или ID закрытой группы (строкой с минусом).
* **Конфигурация в `config.json`:**
  ```json
  {
    "channel": "max",
    "max": {
      "enabled": true,
      "token": "YOUR_MAX_BOT_TOKEN",
      "chatId": "-YOUR_MAX_GROUP_ID"
    }
  }
  ```

---

### 3. Discord (Текстовый канал)
* **Как настроить:**
  - В настройках текстового канала Discord ➔ «Интеграции» ➔ «Создать вебхук».
  - Скопировать Webhook URL.
* **Конфигурация в `config.json`:**
  ```json
  {
    "channel": "discord",
    "discord": {
      "enabled": true,
      "webhookUrl": "https://discord.com/api/webhooks/..."
    }
  }
  ```

---

### 4. Slack / Mattermost (Входящий вебхук)
* **Как настроить:**
  - Добавить приложение *Incoming Webhooks* в рабочий канал Slack/Mattermost.
  - Скопировать сгенерированный URL.
* **Конфигурация в `config.json`:**
  ```json
  {
    "channel": "slack",
    "slack": {
      "enabled": true,
      "webhookUrl": "https://hooks.slack.com/services/..."
    }
  }
  ```

---

### 5. Кастомный Webhook (CRM / 1С / Внутренний бэкенд)
* **Как настроить:**
  - Указать любой URL, принимающий HTTP POST c JSON-телом проводки:
* **Конфигурация в `config.json`:**
  ```json
  {
    "channel": "webhook",
    "webhook": {
      "enabled": true,
      "url": "https://api.mycompany.ru/webhooks/sber",
      "secretHeader": "X-Auth-Token",
      "secretValue": "YOUR_SECRET_TOKEN"
    }
  }
  ```

---

### 6. Только по требованию (On-Demand)
* Если пользователю не нужны фоновые уведомления, служба пушей отключается.
* Все данные (баланс, выписки, создание платёжек) запрашиваются исключительно вручную через прямое общение с ассистентом в чате.
