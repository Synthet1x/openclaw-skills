# 👤 Руководство для человека: Подключение к СберБизнес API

Это пошаговая инструкция, как предпринимателю (ИП или руководителю ООО) получить ключи доступа к официальному **СберБизнес API** для автоматизации работы со счётом.

---

## 🧭 Шаг 1. Вход в СберБизнес и переход в раздел API

1. Откройте интернет-банк [СберБизнес (sbi.sberbank.ru)](https://sbi.sberbank.ru) и авторизуйтесь по СберID, логину/паролю или токену.
2. В левом боковом меню перейдите в раздел **«Все продукты и услуги»** (или введите в строке поиска кабинета слово `API`).
3. Найдите блок **«Интеграция с 1С и другими системами»** и кликните на **«СберБизнес API»**.
4. На откр��вшейся странице нажмите зелёную кнопку **«Подключить»** (или «Создать интеграцию»).
5. **Выбор сервиса:**  
   Выберите пакет услуг **«Компаниям»** (это базовый официальный пакет для выписок, получения остатков в реальном времени, проверки контрагентов и создания платёжных поручений).

---

## 🔑 Шаг 2. Выпуск сертификата безопасности (mTLS)

СберБизнес API работает по стандарту взаимного TLS (mTLS): банк проверяет сертификат вашего бота, а бот проверяет сертификат банка.

1. В окне создания интеграции выберите тип аутентификации: **«Сертификат (mTLS)»**.
2. Нажмите кнопку **«Сформировать сертификат»**:
   - Система Сбера сгенерирует криптографический контейнер.
   - Задайте надёжный пароль для защиты файла сертификата (обязательно запомните его!).
3. Подтвердите выпуск сертификата СМС-кодом или подписью с флеш-токена.
4. Нажмите **«Скачать сертификат»** — на ваш компьютер сохранится файл с расширением **`.p12`** (например, `client.p12` или `sber_client.p12`).

---

## 🏷️ Шаг 3. Получение `Client ID` и `Client Secret`

1. В карточке созданной интеграции найдите блок учетных данных:
   - **Client ID** — открытый идентификатор вашего приложения (строка вида `01234567-89ab-cdef-...`). Скопируйте его.
   - **Client Secret** — закрытый секретный ключ.
2. Нажмите кнопку **«Показать секрет»** (банк запросит подтверждение по СМС).
3. Скопируйте значение `Client Secret`.
4. ⚠️ **Важная особенность Сбера:** секретный ключ Сбера очень часто содержит символ вертикальной черты (`|`). Не пугайтесь, наш скилл автоматически умеет его корректно экранировать.

---

## 🏛️ Шаг 4. Корневые сертификаты Минцифры и Сбера

Для того чтобы ваш бот мог безопасно проверять подлинность серверов Сбербанка:
1. Банк использует сертификаты Национального Удостоверяющего Центра (НУЦ Минцифры).
2. Вы можете скачать официальный доверенный бандл сертификатов на [портале Госуслуг (gosuslugi.ru/crt)](https://www.gosuslugi.ru/crt) или использовать готовый файл `trust_bundle.pem`, который входит в комплект этого скилла.

---

## 🚀 Шаг 5. Безопасная упаковка ключей (Drop & Pack)

Вам **не нужно** отправлять банковские пароли и закрытые ключи в окно чата нейросети! Это небезопасно и нарушает банковскую тайну.

Вместо этого используется простая и безопасная схема:

1. **Скопируйте файл сертификата на сервер:**  
   Положите скачанный из СберБизнес файл `client.p12` в системную защищённую папку:  
   `~/.openclaw/secrets/sber/client.p12`
2. **Запустите мастер настройки в терминале сервера:**
   ```bash
   python3 scripts/sber_vault.py setup
   ```
   - Мастер локально запросит пароль от `.p12`, `Client ID` и `Client Secret` со скрытым вводом (звёздочками);
   - Прямо в оперативной памяти (RAM) распакует сертификат и запечатает всё в аппаратный **Zero-Knowledge Vault (AES-256-GCM)**;
   - Исходный открытый `.p12` будет безопасно затёрт и удалён с диска.
3. **Возвращайтесь в чат к ассистенту:**  
   Просто напишите в диалог: *«Ключи упаковал, проверяй»*.  
   Ассистент сделает проверочный запрос баланса и предложит выбрать канал для мгновенных пушей (Telegram, MAX, Discord, Slack, Webhook).
